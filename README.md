# 🛡 SystemGuard

Мощный системный монитор и твикер для Windows (Avalonia, .NET 10) + Telegram-бот с WebApp-пультом.

## Проекты

| Проект | Что это |
|---|---|
| `SystemGuard.Desktop` | Основное приложение: дашборд, процессы, сеть, игры, Telegram-бот |
| `SystemGuard.Core` | Общие интерфейсы и модели |
| `SystemGuard.KeyGenerator` | Генератор лицензионных ключей |
| `SystemGuard.MiniApp` | Telegram WebApp-пульт (деплой: GitHub Pages → [`systemguard-miniapp`](https://github.com/Marik1337leet/systemguard-miniapp)) |

## Сборка

```powershell
dotnet build SystemGuard.Desktop/SystemGuard.Desktop.csproj
```

Требуется: .NET 10 SDK, Windows 10/11.

## Telegram-бот

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot).
3. В приложении: **Настройки → Telegram** → вставьте токен и Chat ID → **Connect**.
4. В чате с ботом: `/start`. Кнопка **🌐 Web App** открывает мини-приложение.

Команды понимают аргумент в одну строку: `/ls C:\Games`, `/cmd ipconfig`,
`/volume 70`, `/open chrome`, `/close notepad`. Оплата Pro — Telegram Stars.

### WebApp: два режима

* **Live** (рекомендуется): на ПК во вкладке Telegram нажмите **Publish live link**
  (HTTPS-туннель к локальному API по SSH-цепочке: pinggy → localhost.run,
  с автопереподключением; serveo выкинут — отдаёт Permission denied.
  Проверено сквозным стендом: публичная ссылка из интернета отдаёт статус,
  команды и скриншоты. Свежая ссылка после каждого реконнекта сама прилетает
  вам в личку бота — старая умирает, это нормально). В WebApp во
  вкладке **Live** введите ссылку + токен — и прямо в приложении: живые статы,
  скриншоты, MJPEG-видео экрана, кадры камеры, мгновенные слайдеры громкости и
  яркости, файлы с inline-списком и скачиванием, вывод CMD на экране,
  удалённые мышь и клавиатура (тачпад + тап по кадру + печать текста).
* **Relay** (без настройки): команды уходят через `sendData` в бот,
  ответы приходят сообщениями в чат. Токенов в браузере нет.

### Android-приложение: PARKED

Основной клиент — WebApp (ниже). Нативный APK поставлен на паузу: relay
через Bot API из нативного приложения невозможен технически (сообщения от
имени бота ПК не видит). Сейчас APK умеет только Live; вне дома без live
команды — прямо в чате с ботом.

Условия доступа вне дома (любым способом): ПК включён (сон запрещён
автоматически пока live опубликован), приложение запущено, интернет есть.
Бот и live сами стартуют при запуске приложения (автоконнект + автопубликация).

### Важно: Smart App Control режет свежие сборки

Если после `dotnet build` приложение не запускается с ошибкой
`0x800711C7` («Политика управления приложениями заблокировала файл») —
это Smart App Control блочит неподписанные сборки без репутации.
Решение: Параметры → Конфиденциальность и безопасность → Безопасность
Windows → Управление приложениями и браузером → Smart App Control → **Выкл**
(Microsoft сама рекомендует выключать его разработчикам).

### Тесты

- `SystemGuard.Tests/InMemoryCheck.ps1` — работает всегда (проверяет реальные
  исходники без запуска бинарников):
  `powershell -ExecutionPolicy Bypass -File SystemGuard.Tests\InMemoryCheck.ps1`
- `SystemGuard.Tests` (xUnit, 82 теста) + `SystemGuard.Desktop.exe --selftest`
  (58 проверок, включая живой HTTP API на loopback) — полный сквозной прогон
  (relay-протокол, парсеры туннеля, команды, HTTP как с телефона).
  Проверено: всё зелёное. Если вдруг упрётесь в `0x800711C7` — см. пункт про
  Smart App Control выше.

### WebApp

Мини-приложение отправляет команды через `Telegram.WebApp.sendData`
(без токенов в браузере), ответы бота приходят сообщениями в чат.
Хостинг — GitHub Pages (репозиторий `systemguard-miniapp`).

## Производительность

- Опрос железа: раз в ~2 с, без перекрытия тиков, тяжёлая работа вне UI-потока
- Графики обновляются раз в ~4 с (окно 40 точек)
- Трафик сети считается в фоне
- Бот: polling-цикл отделён от исполнения команд, отправка через rate-limit шлюз с обработкой FloodWait (429)
